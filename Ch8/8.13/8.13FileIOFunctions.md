# 8.13 File I/O Functions

1. fopen: opens a file.
2. fclose: closes a file.
3. feof: tests for end of file.
4. ferror: returns the error status of a file.
5. fgetc: reads a single character fromt he specified file and returns it.
6. fputc: writes a single character a file.
7. fscanf: parses formatted text from a file according to the format and writes the results to args.
8. fprintf: writes a formatted string to a file.
9. fread: reads binary data from the file specified by the file descriptor into a register or into a memory.
10. fwrite: writes binary data from a register to the file specified by the file descriptor.
11. readmemeb: reads binary data from a file and stores it in memory.
12. readmemeh: reads hexadecimal data from a file and stores it in memory.
